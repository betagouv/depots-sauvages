# Protect'Envi devient Stop Dépôt Sauvage : pourquoi ce changement de nom ?

> **Résumé** : Vous connaissiez l'outil sous le nom de Protect'Envi ? 
Découvrez pourquoi il s'appelle désormais Stop Dépôt Sauvage, et ce que ce changement implique concrètement pour votre commune.

#### Un nom plus clair pour un outil qui ne change pas

Depuis son lancement, l'outil qui vous permet de générer vos rapports de constatation, ou encore vos lettres d'information s'appelait Protect'Envi. Vous le retrouvez aujourd'hui sous le nom de Stop Dépôt Sauvage.

Rien ne change dans son fonctionnement : mêmes documents générés automatiquement, même accompagnement par l'équipe, même procédure administrative fondée sur l'article L. 541-3 du Code de l'environnement. Seul le nom évolue, pour mieux refléter ce que fait l'outil au quotidien.

#### Pourquoi ce nouveau nom ?

Protect'Envi est le nom du dispositif porté par la Gendarmerie nationale (CESAN) pour accompagner les collectivités dans la lutte contre les atteintes à l'environnement. C'est un nom institutionnel, qui a vocation à couvrir plusieurs actions au-delà du seul traitement des dépôts sauvages.

Stop Dépôt Sauvage, c'est le nom de l'outil que vous utilisez concrètement pour traiter vos dossiers de dépôts sauvages, de la constatation jusqu'à la sanction. Un nom qui dit directement ce qu'il permet de faire, sans détour.

Protect'Envi reste le dispositif institutionnel derrière l'outil. Stop Dépôt Sauvage devient le nom que vous utilisez au quotidien.

***Ce qui change pour vous :***

- Le nom affichés sur le site
- L'adresse à laquelle vous parlez de l'outil auprès de vos collègues ou d'autres communes : https://stopdepotsauvage.beta.gouv.fr

***Ce qui ne change pas :***

- Votre compte, vos dossiers et vos données restent accessibles normalement
- Les documents déjà générés restent valables
- L'équipe qui vous accompagne reste la même
- La connexion via ProConnect ne change pas

#### Vous avez déjà un dossier en cours ?

Aucune action n'est nécessaire de votre part. Vous retrouverez votre dossier tel que vous l'avez laissé, sous le nom Stop Dépôt Sauvage.
