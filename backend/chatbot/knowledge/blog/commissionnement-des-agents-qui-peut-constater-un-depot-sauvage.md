# Commissionnement des agents : qui peut constater un dépôt sauvage ?

> **Résumé** : Qui peut constater un dépôt sauvage dans une commune ? 
Commissionnement, élus, police municipale : le point pour les maires et les agents.

Pour qu’un constat de dépôt sauvage soit solide, il doit être établi par un agent qui en a la qualité. Cette page fait le point sur les agents concernés et sur la démarche de commissionnement.

#### **Qui peut constater ?**

Les élus (maire, adjoints), les agents de police municipale et les gardes champêtres n’ont pas besoin d’être commissionnés : ils peuvent constater un dépôt et en fouiller le contenu dans le cadre de leurs prérogatives.

Les autres agents de la commune, comme les agents des services techniques ou de l’environnement, peuvent être désignés par le maire pour constater, à condition d’être commissionnés par arrêté.

#### **Le commissionnement : de quoi s’agit-il ?**

Le **commissionnement** est la décision par laquelle le maire (ou le président de l’intercommunalité) désigne un agent pour exercer cette mission. Il précise le périmètre de ses compétences.

L’**assermentation** n’est pas requise pour la procédure administrative : un arrêté de commissionnement suffit, sans prestation de serment devant le tribunal.

#### **Les démarches, en pratique**

- Identifier les agents de la commune qui interviennent déjà sur le terrain.
- Prendre un arrêté de commissionnement pour chaque agent concerné.
- Informer l’agent de sa mission : constater les dépôts et rédiger le rapport de constatation.
- Conserver l’arrêté, qui pourra être demandé en cas de contestation.

#### **Et pour la procédure administrative ?**

Commune de petite taille, pas de police municipale : c’est la situation la plus courante, et elle ne bloque pas la démarche. Un simple arrêté de commissionnement suffit pour qu’un agent puisse constater, sans passage devant le tribunal, et le maire ou un adjoint peut aussi constater directement. Stop Dépôt Sauvage permet de générer le rapport de constatation quel que soit l’agent qui le rédige.
